# Salido Resort V12.0.1 — Full Admin Controls

This maintenance release reconnects the V12 public redesign to the Admin Studio.

## Fixed
- Restored all editable website wording in English, Sinhala and Tamil.
- Added section-level controls for navigation, hero, booking, rooms, facilities, gallery, events, location, newsletter and footer.
- Restored editable placeholders, buttons, prices, contact details and labels.
- Retained photo library, look and feel, preview, publish, API and Netlify workflows.
- Fixed the `0 labels` problem caused by missing V12 `data-i18n` mappings.
