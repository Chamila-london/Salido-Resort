# Salido Resort V7.0

Cleaned production package based on the existing Salido Resort website.

## V6 changes
- Removed historical version README files.
- Reliable full-site admin preview with explicit Desktop (1440px), Tablet (768px), and Mobile (390px) modes.
- Desktop preview always displays the complete desktop navigation, independent of the admin column width.
- Compact navigation sizing contract prevents clipping and overlap.
- Existing content editor, translations, galleries, publishing functions, undo, redo, and design reset are retained.

## Run locally
Serve this folder over HTTP (for example with `python -m http.server`) and open `/admin/` for the editor. Opening files directly from a ZIP is not supported.
