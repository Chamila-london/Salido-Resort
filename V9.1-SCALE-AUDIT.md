# Salido Resort V9.1 — Typography & Layout Scale Audit

This release normalizes the public website's visual scale after the V9.0 feature upgrade.

## Updated
- Unified body, heading, label, button and supporting-text sizes.
- Reduced oversized Facilities, Getting to Kandy and Reservation sections.
- Reduced section padding, card padding, form-control height and large empty areas.
- Standardized room-card and gallery dimensions.
- Added responsive tablet/mobile scale rules.
- Preserved V8.0.6 fixed-position navigation, green map marker, admin and all functionality.
