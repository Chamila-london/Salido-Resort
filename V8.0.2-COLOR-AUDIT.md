# Salido Resort V8.0.3 — Colour Audit

- Purple remains the primary brand colour for navigation, active states, booking actions, links, and call controls.
- Primary button hover states now remain purple instead of changing to gold.
- The resort map destination pin now uses a warm gold accent, giving it stronger contrast against dark and satellite map tiles.
- Map direction buttons use the same restrained gold accent to connect the action with the destination marker.
- WhatsApp controls remain green because that colour is a recognized semantic cue.
- Gold is limited to map/location emphasis and does not compete with the main purple brand system.
- No layout, content, navigation sizing, admin, authentication, or publishing behavior was changed.
